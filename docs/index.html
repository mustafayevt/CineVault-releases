Scan, Scrape, Rename

Each title moves through three stages, New, Scraped and Renamed, and you can see where every one of them stands.

  1. Scan

    Add your movie and TV folders. CineVault finds each title and keeps its NFO, artwork, subtitles and trailer files with it. New files show up as New.

  2. Scrape

    Matches each title on TMDB and fetches plot, cast, posters and fanart, with ratings from IMDb, Rotten Tomatoes, Metacritic, Trakt and Letterboxd. Writes NFO files and artwork that Kodi, Jellyfin and Emby read.

  3. Rename

    Renames folders and files from a naming template. You see every change before it happens, the extra files move along, leftovers go to a trash folder, and Undo puts it all back.

The whole film on one page

Plot, cast and crew, every rating side by side, the video and audio formats from the file itself, and the artwork in each slot. Change anything by hand and it is written back to the NFO.

  • Ratings from TMDB, IMDb, Rotten Tomatoes, Metacritic, Trakt and Letterboxd
  • Kodi, Jellyfin and Emby NFO files, posters, fanart and logos
  • Trailers found on TMDB and downloaded next to the movie

Tidy names, and nothing moves until you say so

Pick a naming style or write your own template. The preview strikes out what goes and shows what each folder becomes. Apply it when it looks right; every batch can be undone.

Subtitles your TV can play

Many TV players can't read the subtitle tracks inside an MKV. CineVault saves them as SRT files next to the video, in the languages you choose, and leaves the video untouched.

Keep it open on a second monitor

Make the window narrow and CineVault becomes a companion view: the sidebar folds behind a menu button and each page fits one column, so the title you are watching stays in view beside the player.

Updates itself

CineVault checks for new versions and installs only builds signed with the project key.

Get started

  1. Download and run the installer

    The installer isn't code-signed yet, so Windows SmartScreen may stop it the first time. Click through the warning:

    Windows protected your PCMore infoRun anyway

  2. Add a free TMDB key

    Create an account at themoviedb.org and request an API key. Paste it in when CineVault first starts. OMDb and MDBList keys are optional and add more ratings.

  3. Add your folders

    Point CineVault at your movie and TV folders. It scans them, and you Scrape and Rename from there.

System requirements

Windows
Windows 10 or 11, 64-bit, with Microsoft Edge WebView2. It is built into Windows 11, and the installer downloads it on Windows 10 when it is missing.
macOS
Coming soon.
Internet
Needed to Scrape and to check for updates. Your library and settings stay on your computer.

This product uses the TMDB API but is not endorsed or certified by TMDB. Ratings come from OMDb and MDBList when you add their keys.
